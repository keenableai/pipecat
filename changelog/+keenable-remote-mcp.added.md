- Added an `examples/mcp/mcp-keenable-remote.py` example: a voice bot grounded by Keenable's **hosted remote MCP server** (`https://api.keenable.ai/mcp`, MCP Streamable HTTP transport). It connects with the built-in `MCPClient` + `StreamableHttpParameters` and registers the server's `search_web_pages`, `fetch_page_content`, and `submit_search_feedback` tools on the LLM — no local MCP server process and no Keenable client code required. Works keyless (free tier) by default; forwards `KEENABLE_API_KEY` as `X-API-Key` and sends a tagged `keenable-pipecat-mcp/<version>` User-Agent when set.
