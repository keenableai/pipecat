- Added a Keenable web search integration at `pipecat.services.keenable.search`. Ships `KeenableSearchClient` (an async wrapper around Keenable's `/v1/search` and `/v1/fetch` endpoints) plus a ready-to-register `keenable_search` LLM tool handler and `KEENABLE_SEARCH_FUNCTION_SCHEMA`, so any LLM service (OpenAI, Groq, Anthropic, etc.) can ground answers with live web results in one line: `llm.register_function("keenable_search", keenable_search)`. See `examples/keenable-search/` for a full bot.
