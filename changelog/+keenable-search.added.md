- Added a Keenable web search + page fetch integration at `pipecat.services.keenable.search`. Ships `KeenableSearchClient` (an async `httpx` wrapper around Keenable's `/v1/search` and `/v1/fetch` endpoints) plus two ready-to-register LLM tools — `keenable_search` / `KEENABLE_SEARCH_FUNCTION_SCHEMA` and `keenable_fetch` / `KEENABLE_FETCH_FUNCTION_SCHEMA` — so any LLM service (OpenAI, Groq, Anthropic, etc.) can ground answers with live web results in a couple of lines: `llm.register_function("keenable_search", keenable_search)`. Works with **no API key** against Keenable's free, keyless public endpoints, and upgrades to the authenticated endpoints when `KEENABLE_API_KEY` is set; the base URL comes from `KEENABLE_API_URL` (HTTPS-enforced). Per-query `site`/date filters are exposed to the model, and HTTP errors surface as typed `KeenableError` subclasses (`KeenableAuthError`/`KeenableInsufficientCreditsError`/`KeenableRateLimitError`). See `examples/keenable-search/` for a full bot.
