- Added a real-time voice fact-checking example at `examples/voice-fact-checking/`. It fact-checks a live conversation/conference transcript *as it streams* (interim + final transcripts, no waiting for utterance end): a prompt-driven trigger extracts check-worthy claims and search queries, Keenable verifies them on the web, and an LLM judge returns supported/refuted/unverified verdicts that render in a custom UI as green/red/amber claim cards with explanations and sources. Includes tight cost/volume controls (cooldown, per-session budget, de-duplication, concurrency caps) with a live cost meter, and a GEPA optimizer (`gepa_optimize.py` + `dataset.json`) to evolve the trigger prompt.
